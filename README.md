# 🌱 AgriAssist – AI-Powered Smart Agriculture Advisory Platform

AgriAssist is an AI-powered web-based agriculture advisory platform designed to provide farmers with multiple agricultural services through a single application.

The platform combines **plant disease detection, an AI agricultural chatbot, real-time market prices, and government agricultural schemes** to provide accessible and timely farming information.

## 🚀 Key Features

* 🌿 **Plant Disease Detection** – Detect plant diseases from uploaded leaf images using a pre-trained deep learning model.
* 💬 **AI Agricultural Chatbot** – Provides agriculture-related guidance using **RAG, Ollama, and Llama 3.2**.
* 📈 **Market Prices** – Retrieves real-time agricultural market price information through the **Data.gov.in API**.
* 🏛️ **Government Schemes** – Provides information about relevant agricultural government schemes.
* 🌐 **Web-Based Interface** – Simple and user-friendly interface designed for farmers.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, FastAPI
* **AI/ML:** Hugging Face Deep Learning Model
* **LLM:** Llama 3.2
* **Local LLM Runtime:** Ollama
* **AI Technique:** Retrieval-Augmented Generation (RAG)
* **API:** Data.gov.in

## 🔄 System Workflow

1. User interacts with the web application.
2. User uploads a plant image, asks an agricultural question, checks market prices, or accesses government schemes.
3. The request is processed by the FastAPI backend.
4. The appropriate AI model, RAG pipeline, or external API processes the request.
5. The result is displayed to the user.

## 🎯 Objective

The main objective of AgriAssist is to reduce farmers' dependence on multiple applications by providing essential agricultural information and AI-powered assistance through a unified platform.
